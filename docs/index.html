.\invoke.ps1 --help

Built for how MSPs actually work

⚡ Instant Start

Start tracking with a single command. No project setup, no clicking through menus—just type and go.

⏸️ Pause & Resume

Interrupted by a call? Pause tracking, handle it, resume exactly where you left off.

💰 Billable Tracking

Mark time as billable, set hourly rates, and see value add up in real-time.

📊 Daily & Weekly Views

See where your time went with quick summaries. Visual bars make patterns obvious.

📁 JSONL Storage

Human-readable, append-only format. Easy to backup, sync, or analyze with any tool.

🔧 PowerShell Native

Works seamlessly in your existing MSP scripts and automation workflows.
